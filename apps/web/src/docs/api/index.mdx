# API Overview

The Orbit API is a REST API that powers the dashboard and all public integrations. Every request goes to your API server's base URL:

```
https://api.yourdomain.com
```

Replace `api.yourdomain.com` with your actual API server address. If you're self-hosting, this is the value you set for `ORBIT_API_URL`.

## Authentication

Every public API request must include your API key in the `X-API-Key` header:

```http
GET /api/v1/w/your-workspace/test
X-API-Key: orb_api_xxxxxxxxxxxxxxxx
```

Keys are workspace-scoped — a key only works with the workspace it was created in. See [Authentication](/docs/api/authentication) for full details on key types and how to pass your credentials.

## Responses

All responses are JSON. There is no envelope or wrapper object — success responses return the natural shape of the resource. Errors always return an object with a `message` field:

```json
{ "message": "Invalid API key." }
```

### Common status codes

| Status | Meaning |
| --- | --- |
| `200 OK` | Request succeeded |
| `201 Created` | Resource was created |
| `400 Bad Request` | Validation error — check the `message` field |
| `401 Unauthorized` | API key is missing or invalid |
| `404 Not Found` | Workspace not found, or key doesn't belong to this workspace |
| `429 Too Many Requests` | Rate limit exceeded — see `Retry-After` header |
| `500 Internal Server Error` | Something went wrong on our end |

## Rate limiting

Public API endpoints are rate-limited per workspace. When you exceed a limit, the API responds with `429 Too Many Requests` and a `Retry-After` header telling you how many seconds to wait before retrying.

Every response from a public endpoint includes rate limit headers so you can track your usage proactively. See [Rate Limits](/docs/api/rate-limits) for limits, headers, and how to handle `429` gracefully.
