# Docker

The recommended self-host setup is `docker-compose.selfhost.yml` in the repo root.

## Stack

The compose file starts two services:

| Service | Image | Purpose |
| --- | --- | --- |
| `db` | `postgres:16-alpine` | PostgreSQL source of truth |
| `app` | `ghcr.io/projectkura/orbit` | Orbit (dashboard + API + auth) |

A Dragonfly (Redis-compatible) cache is optional for enhanced rate limiting.

## Quick start

```bash
cp .env.example .env
# edit .env — set ORBIT_WEB_URL, ORBIT_API_URL, BETTER_AUTH_SECRET, POSTGRES_PASSWORD
docker compose -f docker-compose.selfhost.yml up -d
```

Migrations run automatically on first API request.

## Reverse proxy

Use Nginx or Caddy to terminate SSL:

```
orbit.example.com {
  reverse_proxy app:3000
}
```

## Updating

```bash
docker compose -f docker-compose.selfhost.yml pull
docker compose -f docker-compose.selfhost.yml up -d
```
